# Overview

The purpose of this project is to show a Steam profile's playtime and top games.
They are then visualized both in the Data and Chart tabs. 

# Dataset Used

I used Steam's public API to get the data from Steam servers.

# Instructions

The project works without any user input, as the default profile found on the site is my own profile. 
If a user wants to look at a specific profile, they can either enter the link, such as:

```https://steamcommunity.com/profiles/<17 Digit Profile ID>```

or

``<17 Digit Profile ID>``

into the Overview page's text input.

Aside from that, there's nothing much else to do besides interacting 
with the charts and sliders with mouse clicks and drags. Enjoy!
